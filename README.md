## What Scout Does

Scout provides a structured workspace for teams handling recruitment and applicant tracking. The web application brings candidates, hiring stages, and recruitment progress together so users can follow activity from a central location.

Its pipeline-oriented design is suited to organizations that want to arrange applicants and monitor their movement through the hiring process without splitting each stage across separate tools.

---

## Core Capabilities

- Structure and manage an active hiring pipeline
- Follow applicants throughout recruiting activities
- See candidate movement across the relevant hiring stages
- Handle applicant tracking through a web interface
- Consolidate recruitment activity in one view
- Coordinate hiring work from a dedicated workspace
- Check pipeline status within a single application

## Using Scout

A standard session can follow this sequence:

1. Launch the Scout web application.
2. Add applicants to the pipeline or inspect existing entries.
3. Place applicants in the recruiting stage that reflects their current status.
4. Monitor progress as hiring coordination continues.
5. Revisit the application as candidates advance through the process.

Exact workflow behavior is determined by the current application build and the interface it provides.
